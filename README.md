## About Me

I'm a **fullstack developer** who enjoys taking an idea all the way from the database to the pixel on the screen. I like writing clean, maintainable code, designing solid APIs and building interfaces that feel fast and simple.

- Working mostly with **.NET** on the backend and modern **JavaScript** on the frontend
- Using **Python (FastAPI)** and **Go** for services, tools and side projects
- Constantly exploring new technologies and better ways to build software
- Open to collaborating on interesting projects
- Ask me about **C#, .NET, APIs, SQL** and fullstack architecture
- Fun fact: I learn best by building; most of my repos started as *"let me just try this"*
